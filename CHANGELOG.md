# Changelog

## 0.1.0 — 2026-10-06

Initial camera toolkit release: shared Frame/Camera API, backend registration and support descriptions, GUI/CLI and diagnostics, PNG/TIFF plus raw-sensor export, simulated and OS-video adapters, verified GR300/TCA3.1MP USB capture, exact native rendering, worker isolation, and Mac arm64 / Windows x64 portable packages. Windows measurements reached approximately 35.4 fps live and 9 fps full-resolution; Mac's new real-camera timing awaits measurement.
