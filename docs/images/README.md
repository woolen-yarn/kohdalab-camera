# UI screenshot provenance

`image-controls.png` and `camera-picker.png` (where present) are historical
macOS Simulation layout examples captured for the existing image-first GUI.
The displayed title may show 0.1.9. They are not validation evidence for 0.1.13.
The current release targets Windows x64; this Mac screenshot does not imply a
published Mac package. Current control-adapter acceptance uses an explicit fake
GUI and is recorded separately in the common API validation document.
